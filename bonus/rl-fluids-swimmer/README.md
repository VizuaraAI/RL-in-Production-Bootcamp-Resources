# RL Meets Fluid Mechanics — the bonus lecture

**RL in Production · Bonus Lecture · Vizuara AI Labs**
Slides: https://rl-bootcamp-decks.vercel.app/lecture-bonus-rl-fluids/

Two laptop-scale problems where reinforcement learning solves real fluid dynamics.
No GPUs. No CFD packages. Pure numpy, minutes of training, and a published paper
behind each result.

| | Problem 1 — navigation | Problem 2 — the gait |
|---|---|---|
| question | **where** should a weak swimmer go? | **how** should a micro-swimmer move at all? |
| physics | Taylor–Green vortex lattice (exact solution) | Stokes flow, Oseen mobility, force-free |
| the enemy | a current 3× faster than you | the scallop theorem (reciprocal strokes = 0) |
| brain | Q-table, 144 cells × 8 headings | Q-table, 4 shapes × 2 toggles = **8 numbers** |
| replicates | Biferale et al., *Chaos* 2019 | Tsang et al., *PRFluids* 2020 / Najafi–Golestanian 2004 |
| result | naive arrives **57.9%** → learned **100%** | reciprocal **−0.0003** → learned **+0.103** (≈350×) |

## Problem 1 — Zermelo navigation ("windy gridworld, but the wind is real")

A robot swims at fixed speed `v_s = 0.3` through the Taylor–Green lattice
(`u_x = U cos x sin y`, `u_y = −U sin x cos y`, `U = 1.0`) and must reach a
target disc. The state is only *which cell of a 12×12 grid it is in*; actions
are 8 compass headings; reward is −1 per decision, +200 on arrival.

The **naive baseline** — point straight at the target, chosen from the same 8
actions — is honest and fails honestly: wherever the opposing jet exceeds
`v_s`, headway is physically impossible, and 42% of naive robots end trapped in
closed orbits around vortices. Q-learning (512 parallel robots sharing one
table) reaches **100% arrival**, discovering tacking detours and even routes
that wrap the periodic boundary because that direction rides the current.

## Problem 2 — the gait (beating the scallop theorem)

The Najafi–Golestanian swimmer: three spheres on a line, two arms, each
Extended or Contracted. Every substep solves the **force-free Stokes mobility
problem** (Oseen interactions, 3 linear equations) — displacement per stroke
*emerges from the hydrodynamics*, it is never looked up.

State = arm configuration (4), action = toggle one arm (2), reward = signed
centre-of-mass displacement. The 8-number Q-table rediscovers the published
non-reciprocal cycle `(E,E)→(C,E)→(C,C)→(E,C)`. The reciprocal baseline
measures −0.0003 after 24 strokes — the scallop theorem, confirmed by our own
physics — vs +0.103 for the learned gait. Order of magnitude agrees with the
Najafi–Golestanian asymptotic `Δ ~ a·ε²/L²` (our ε/L = 0.4 is not small, so an
O(1) factor is expected).

## What we tried first — and why it's in the repo

Before navigation we built the harder **gyrotactic torque-control** problem
(Colabrese et al., *PRL* 2017): actions bias a weak righting torque against
vortex spin. In the regime where the naive swimmer struggles, the vortex is
16× stronger than the control — and an **exact-MDP oracle** (fit the empirical
transition matrix from random rollouts, solve by value iteration) proved that
*even the optimal policy* for every observation we tried gained only 9–25%.

That analysis lives in the lecture as the honest lesson: **control authority >
sensing > algorithm**. Before blaming Q-learning, solve the MDP exactly — the
oracle is 30 lines and it will tell you whether the environment permits the
win you're hoping for. `swimmer/env.py` keeps the gyrotactic world (with the
observation ablations) so you can try to find a regime where it works —
that's the open stretch problem.
